# Research

**Navigation:** [project passport](../README.md) · [architecture overview](../architecture/overview.md)

Discovery notes, comparisons, and design alternatives explored while shaping the Branching Tales demo.

## Purpose

Research lives outside `architecture/` so that exploration can be messy without polluting the source-of-truth specs. Once a research note matures into a decision, it becomes an ADR; once it matures into a contract, it becomes a spec.

## Conventions

- One topic per file, named `{kebab-slug}.md`.
- Each file opens with: question, status (Open / Concluded / Abandoned), owner.
- Conclusions link out to the resulting ADR / spec / BR.
